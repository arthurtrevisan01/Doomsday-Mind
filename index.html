🧠 O que é o método Doomsday?

Criado pelo matemático John Horton Conway, o método Doomsday permite calcular mentalmente o dia da semana de qualquer data do calendário gregoriano. A ideia central: em todo ano, um conjunto de datas fáceis de memorizar cai sempre no mesmo dia da semana — o "Doomsday" (dia do juízo) daquele ano.

O cálculo tem 3 etapas:

  1. Âncora do século — cada século tem um dia-âncora fixo.
  2. Doomsday do ano — desloca a âncora conforme o ano dentro do século.
  3. Ajuste do mês/dia — compara a data pedida com a data-referência do mês.

1️⃣ Âncoras dos séculos

As âncoras se repetem a cada 400 anos:

SéculoÂncora
1700–1799Domingo
1800–1899Sexta-feira
1900–1999Quarta-feira
2000–2099Terça-feira
2100–2199Domingo

💡 Fórmula: âncora = (5 × (século mod 4) + 2) mod 7, onde século = ⌊ano/100⌋ e 0 = domingo. Mnemônico em inglês: "We-in-dis-day" → 1900 = Wednesday (quarta), 2000 = Tuesday (terça).

2️⃣ Doomsday do ano

Pegue os 2 últimos dígitos do ano (y) e calcule:

a = ⌊y ÷ 12⌋  •  b = y mod 12  •  c = ⌊b ÷ 4⌋
Doomsday = (âncora + a + b + c) mod 7

Exemplo (1985): y = 85 → a = 7, b = 1, c = 0 → 7+1+0 = 8 ≡ 1 (mod 7). Âncora de 1900 = quarta (3). 3 + 1 = 4 → quinta-feira.

Alternativa: método "Ímpar + 11"

  1. Se y é ímpar, some 11.
  2. Divida por 2.
  3. Se o resultado é ímpar, some 11.
  4. Calcule 7 − (resultado mod 7) → esse é o deslocamento a somar na âncora.

🔢 Exemplo completo: 20/07/1969 (chegada à Lua)

  1. Século 1900 → âncora = quarta (3).
  2. y = 69 → a = ⌊69/12⌋ = 5, b = 69 mod 12 = 9, c = ⌊9/4⌋ = 2 → 5+9+2 = 16 ≡ 2. Doomsday = 3+2 = 5 → sexta.
  3. Referência de julho: 11/07 (sexta). Do dia 11 ao 20 são 9 dias → 9 mod 7 = 2. Sexta + 2 = domingo. ✅

💡 Ano bissexto: divisível por 4, exceto múltiplos de 100 que não sejam múltiplos de 400. (2000 foi bissexto; 1900 não.)
